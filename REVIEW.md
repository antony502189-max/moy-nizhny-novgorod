# Review: что сделано и что требует доработки

Дата слияния с репозиторием Антона: 17.11.2026 20:54 (МСК).
Автор: Claude (Sonnet 5.5) для Андрея. Приложение «Нижний для гостей», гостевой слой «Мой Нижний Новгород», хакатон GORKYCODE 2026, трек «Туризм».

## Структура репозитория после слияния

- Исходники нового приложения (Vite + React + TS): `src/`, `api/`, `public/`, `scripts/`, `index.html`, `README.md`. `README.md` и `index.html` в корне теперь мои.
- Файлы Антона (собранный прототип) лежат рядом без изменений: `assets/`, `places/`, `housing/`, `sw.js`, `manifest.webmanifest`, `runtime-config.json` и другие. Его `index.html` и `README.md` заменены моими, поэтому его собранная версия как сайт больше не откроется из корня. Сборка не нужна, пока она не будет заново подключена к Pages. Его прежние версии доступны в истории (`git show anton/main:index.html`).
- Переиспользованы его данные и фото: 21 место с координатами, 27 фото с лицензиями (`photoCredits.json`).

## Что сделано (проверено в браузере 16–17.11.2026, 400×820)

1. **«Сейчас в Нижнем»** (`#/now`): афиша на 3 часа, закат (считается на устройстве), 5 точек для заката, ближайший туалет и вода, слои на карте OSM (туалеты, вода, безбарьерные места, лестницы). Данные об удобствах из OSM: 861 объект на 16.11.2026.
2. **«Тогда / сейчас»** (`#/history`): 5 мест, слайдер, история, «угадай год» (4 раунда). Старые фото из Wikimedia Commons с пометкой Public domain, подписи авторов и лицензий видны.
3. **«Сообщить городу»** (`#/report`) и **панель города** (`#/dashboard`): без входа, категория, фото по желанию, точка на карте, RU/EN/ZH, хранение в `localStorage`. На панели тепловая карта и счётчики по районам, дням и категориям.
4. **ИИ-маршрут** (`#/tour`): serverless-прокси `api/tour.ts` (ключ только на сервере), проверка ответа модели по реальным данным, детерминированный офлайн-планировщик, озвучка остановки через браузерный TTS.
5. **Побратимы** (`#/twin`): приветствие для Минска, Гомеля, Витебска, Сухума.

Доработки после ревью: проверка Origin и лимит размера на прокси, защита от падений на повреждённом `localStorage`, плашка «черновик» у побратимов, помечены демо-пины афиши, «завтра» после последнего события, текст подсказок карты безопасен от HTML, фокус и Escape у карточки места, смена заголовка вкладки, лимит кеша service worker.

## Что мок (выдумано или черновик)

- Афиша (`src/data/events.ts`) и данные панели (`features/dashboard/synthetic.ts`, ~420 записей) — выдуманы, помечены «демо-данные».
- Районы на панели определяются по ближайшему условному центру, это не официальные границы.
- Тексты побратимов — черновик. Китайский машинный, нужна проверка носителем.

## Что не проверено

- ИИ-маршрут не проверялся с настоящей LLM (ключа не было). Путь через прокси проверен на локальном фейковом OpenAI-совместимом сервере.
- Service worker не проверен в настоящем Chrome (во встроенном браузере регистрация не прошла).
- Модель по умолчанию `claude-haiku-5-5` в `TOUR_MODEL` не подтверждена ключом, проверить при первом запуске.
- Лицензии фото сверены по Commons API 16.11.2026, перед коммерческим использованием проверить ещё раз.
- Фото гимназии (около 1900) и ярмарочной открытки («до 1944») нужно подтвердить: то ли здание, годится ли как Public domain.

## Требует доработки

### Перед публичным показом
1. **Rate-limit для `/api/tour`**: без него любой может тратить ключ (Vercel Firewall или Upstash).
2. **Деплой**: Vercel нужен для ИИ-прокси; GitHub Pages даёт только офлайн-планировщик. Нужно решить и подключить сборку (пример workflow в `README.md`). Сейчас корень репозитория содержит и мою сборку, и собранные файлы Антона.
3. **Реальные источники**: афиша и API «Обращений». Формат подключения описан в `README.md`.
4. **Тайлы OSM**: для нагрузки нужен свой провайдер (политика OSM).

### Продукт
5. Режим «от жителя» с рейтингами не реализован.
6. Линии маршрута на карте прямые, не пешеходная навигация.
7. Закатные точки отобраны по описаниям, направление проверять на месте.
8. Нет серверного хранилища: обращения живут только на устройстве.
9. Тексты побратимов: проверить факты и перевод.

### Код (мелочи)
10. Маркеры карты перерисовываются целиком при выборе.
11. Флаг Сухума заменён на «·», у эмодзи флага Абхазии нет отображения.
12. Нет автотестов (проверялось вручную и сборкой).
13. Сайты официальных страниц есть только у 5 мест, у остальных «уточнить».
