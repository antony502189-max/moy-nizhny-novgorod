# Итог проверки · 18 ноября 2026

Основой послужило слияние гостевого приложения с городским в коммите `2162618`. Гостевой режим остаётся главной страницей. Городской интерфейс открывается по ссылке «Для жителей» и по ранее выданным ссылкам на дома и личные маршруты.

## Что изменилось после слияния

- Подложка и поиск адресов встроены в сайт. Уличная сеть даёт пешие пути для всех 420 направлений между остановками, в том числе в профиле без отмеченных лестниц. Внешний навигатор можно открыть по ссылке.
- Маршруты формируются на устройстве с учётом продолжительности, тем, заката и выбранных пользователем оценок. Онлайн-модель включается отдельно при настроенном прокси. Расход ограничивается до обращения к провайдеру. Путь без ключей проверяется самостоятельно.
- Статическая афиша содержит пять датированных мероприятий Арсенала со ссылками на организатора. Прошедшие записи исчезают. Редактор обновляет файл при следующем выпуске.
- Черновик с фото и точкой можно снова открыть и перенести в городскую интернет-приёмную. Панель по умолчанию считает местные записи. Синтетическая выборка доступна по переключателю. Район определяется по границам OSM.
- Сохранены исторические пары и игра. Сравнение у гимназии теперь привязано к площади. В разделе для гостей есть ссылки на сообщения администрации о сотрудничестве, в том числе по Витебску.
- Для GitHub Pages из корня ветки готовится обычная HTML/JS-сборка. Service worker предварительно сохраняет оба режима, все документы справочника, изображения и карты. Загрузка новой версии сохраняет работоспособность открытой вкладки.

## Границы проверки

Доменные тесты покрывают прежние сценарии жителя, бюджеты прогулок, обе сети пеших путей, даты афиши, границы районов, ошибку записи черновика и отказ модели при исчерпании квоты. Работа браузера проверяется на статической production-сборке по подпути, с включённым service worker, заблокированными внешними запросами и отключённой сетью после первой загрузки.

Онлайн-маршрут и распознавание русского запроса проверены с действующим сервисом DeepSeek через локальные серверные функции. Браузер записывал подготовленную русскую фразу с виртуального микрофона. Счётчик расходов в этом тесте был локальным, отказ и исчерпание квоты проверены отдельно. Публичная подача обращения выполняется пользователем на сайте города. Участки прогулок описывают сохранённое состояние OSM. Для оценки реальной доступности, качества перевода носителем и текущих условий нужен осмотр или редакционная проверка. Авторские сведения о фотографиях взяты со страниц файлов и остаются доступны в карточках.

## Проверка интерфейса

На production-сборке с отключённой сетью проверены 54 точки, шесть готовых прогулок в обоих режимах, девять архивных кадров семи объектов, четыре города-партнёра, оценка и перенос гостевой истории, подсказка рядом с остановкой и сохранение фотографии после прогулки. Браузер воспроизвёл встроенную русскую запись и получил частичный ответ HTTP 206 при перемотке. В этих сценариях не зарегистрировано внешних запросов и ошибок JavaScript.

В проверку вёрстки входят ширины 320, 390, 768 и 1280 пикселей, альбомная ориентация и двойной размер текста нижнего меню. Меню занимает отдельную строку экрана. Надписи кнопок и область прокрутки проверяет `npm run test:browser`. После исправления контраста axe-core не сообщил нарушений в проверенных сценариях WCAG A/AA. На титульных экранах используются фотографии мест, авторы и источники доступны в карточках.
