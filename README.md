# Мой Нижний Новгород

Готовая статическая сборка самостоятельной веб-версии городского приложения.

Сайт: https://antony502189-max.github.io/moy-nizhny-novgorod/

Карты: Leaflet, данные © OpenStreetMap contributors. Городские ограничения из исходной записи отмечены как справочные данные.

## Возможности без закрытого API

Свои маршруты из 2–30 остановок, изменение порядка, посещения и заметки,
передача маршрута по ссылке (только название и остановки), резервная копия личных данных.
Личные данные хранятся в браузере; загрузка пользовательских файлов на сервер не выполняется.

## Данные о домах

9 805 эксплуатируемых домов города Нижнего Новгорода. Сведения на август 2026;
публикация исходной выгрузки 17 сентября 2026. У 8 173 домов указана управляющая организация.
Это снимок, не актуальная онлайн-справка и не полный адресный реестр города.

Источник: Минстрой, ГИС ЖКХ; обработка «Если быть точным».
https://tochno.st/datasets/gisgkh
Лицензия: Creative Commons Attribution 4.0 — https://creativecommons.org/licenses/by/4.0/
Изменения: выборка города и эксплуатируемых домов, удаление повторов по GIS GUID,
сокращение полей, координаты только с признаком точного геокодирования.
Метаданные, исходная ссылка и SHA-256 находятся в housing/manifest.json.

Свои выгрузки CSV UTF-8 и JSON можно импортировать в «Мой дом» с предпросмотром,
учётом дубликатов, источника и даты. XLSX предварительно сохраните как CSV UTF-8.
Встроенный справочник и импорт доступны локально; карты и внешняя навигация требуют сеть.
