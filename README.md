# Нижний для гостей — гостевой слой «Мой Нижний Новгород»

Прототип для хакатона GORKYCODE 2026 (трек «Туризм»). Веб-приложение, mobile-first, PWA-light, RU по умолчанию, EN и 中文.
**Это не официальный сервис города.** Все данные, помеченные «демо-данные», выдуманы для показа.

Что внутри (по приоритету):

| # | Модуль | Путь | Статус |
|---|--------|------|--------|
| 1 | «Сейчас в Нижнем»: афиша на 3 часа, закат + точки, карта удобств (туалеты, вода, безбарьерные места, лестницы) | `#/now` | работает; афиша — демо |
| 2 | «Тогда / сейчас»: слайдер, история, «угадай год» | `#/history` | работает; 5 мест, реальные открытые фото |
| 3 | «Сообщить городу» + панель города | `#/report`, `#/dashboard` | работает; хранение локально, панель — синтетика + ваши реальные сообщения |
| 4 | ИИ-маршрут по запросу + офлайн-планировщик | `#/tour` | работает; LLM — через serverless-прокси, без ключа — офлайн |
| 5 | Гостям из городов-побратимов | `#/twin` | работает; тексты — черновик для проверки |

## Запуск

```bash
cd app
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # tsc + vite build -> dist/
npm run preview
```

Node 20+ (проверено на 22). Для репетиции можно подставить время: `http://127.0.0.1:5173/?now=14:30#/now` (меняет «сейчас» только в приложении).

## Переменные окружения

Секреты — только на сервере (Vercel → Project → Settings → Environment Variables), в клиент они не попадают. Не добавляйте префикс `VITE_` к ключам.

| Переменная | Где | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | сервер | ключ для ИИ-маршрута (Anthropic Messages API). Без ключа работает офлайн-планировщик |
| `TOUR_MODEL` | сервер | необязательно, по умолчанию `claude-haiku-5-5` |
| `LLM_BASE_URL`, `LLM_API_KEY` | сервер | вместо Anthropic — любой OpenAI-совместимый `/chat/completions` (OpenRouter, свой шлюз) |
| `VITE_TOUR_API` | клиент (сборка) | необязательно: полный URL прокси, если фронт и API на разных доменах |
| `VITE_REPORT_ENDPOINT` | клиент (сборка) | необязательно: URL, куда дополнительно отправлять обращения (POST JSON без фото). Для демо не нужен |

Шаблон: `.env.example`. Локально положите значения в `.env.local` (он в `.gitignore`).

## Деплой

**Vercel (рекомендуется — работает и ИИ-прокси):** Import Project → корень `app/` → всё остальное подхватит `vercel.json`. Добавьте `ANTHROPIC_API_KEY`. Проверка: `curl -X POST https://<домен>/api/tour` отвечает `{"error":"bad_request"}` (прокси жив; без ключа ответ `{"error":"no_key"}`).

**GitHub Pages:** собрать `npm run build`, опубликовать `dist/` (в `vite.config.ts` стоит `base: './'`, роутинг по хэшу — переписывание URL не нужно). Serverless-функций на Pages нет, поэтому ИИ-кнопка автоматически использует офлайн-планировщик (в консоли будет один 404 на `./api/tour` — это ожидаемо; можно задать `VITE_TOUR_API` на Vercel-прокси). Пример workflow:

```yaml
# .github/workflows/pages.yml (в корне репозитория; если app/ лежит в подпапке — добавьте working-directory)
on: { push: { branches: [main] } }
permissions: { contents: read, pages: write, id-token: write }
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: { name: github-pages }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci && npm run build
      - uses: actions/upload-pages-artifact@v3
        with: { path: dist }
      - uses: actions/deploy-pages@v4
```

Сервис-воркер (`public/sw.js`) кеширует оболочку и данные для офлайна; в dev он не регистрируется.

## Архитектура и как добавить новый трек

```
src/
  core/        i18n, hash-router, Leaflet-обёртка, солнце, геометрия, иконки, UI-кирпичики
  data/        places.ts (21 место), history.ts, events.ts (ДЕМО), twin.ts, amenities.json (OSM), photoCredits.json
  features/    <модуль>/{index.ts, <Page>.tsx, strings.ts}  ← один модуль = один трек/продуктовая область
    registry.ts  список модулей (порядок = порядок вкладок)
api/tour.ts    serverless-прокси к LLM
scripts/fetch-amenities.mjs   обновление удобств из OpenStreetMap
```

Новый модуль: создать `src/features/<id>/` с `FeatureModule` (`id`, `path`, `tab?`, `Component`, `strings` на ru/en/zh), добавить в `registry.ts` — маршрут, вкладка и переводы подключатся сами. Новый язык: добавить код в `LANGS` (`src/core/i18n.tsx`) и ключи в каждый `strings.ts` (отсутствующие ключи падают на ru/en); контент `L10n` также откатывается на en/ru.

## Как это работает: ИИ-маршрут

1. Клиент отправляет `POST /api/tour` `{prompt, lang, catalog}` (каталог — сжатый список наших мест).
2. Прокси добавляет ключ, просит LLM вернуть JSON `{title, summary, stops:[{id,minutes,note}]}` **только из каталога**.
3. Клиент валидирует ответ по реальным данным: неизвестные id и места, нарушающие «без подъёмов/с коляской», отбрасываются; вне бюджета времени — ответ отклоняется.
4. Если API недоступен/нет ключа/ответ плохой — детерминированный офлайн-планировщик (`features/tour/planner.ts`) строит маршрут по тем же данным (теги, время, подъёмы, закат — последним пунктом, «выходите в …»).
5. Ссылки на билеты — только `site` из данных; иначе «уточнить». Озвучка остановки — браузерный TTS, подпись «описание из справочника (официальный источник)». Режим «от жителя» с рейтингами не реализован.

Заметка по безопасности: прокси ограничивает длину запроса (400 симв.) и каталога (60 мест); для публичного запуска добавьте rate-limit (Vercel Firewall / Upstash) — иначе кто угодно сможет тратить ваш ключ.

## Демо-сценарий на 3 минуты

Подготовка: открыть на телефоне/в окне 400 px, язык RU; перед выступлением очистить данные («Ещё → Сбросить»); для воспроизводимости `?now=14:30` (до заката ≈ 1 ч 10 мин в ноябре).

1. **0:00–0:40 «Сейчас».** «Приезжий открывает приложение: что идёт ближайшие 3 часа (афиша — демо, подписано), закат сегодня 15:4x и где его встретить, ближайший туалет и вода в метрах.» Включить слои «Безбарьерно» и «Лестницы» на карте.
2. **0:40–1:20 «Тогда/сейчас».** Дмитриевская башня: ползунок, вкладка «до 1895», затем «Угадай год» — зал отвечает, показываем ответ и ползунок. Фразу «фото из открытых архивов, лицензии под слайдером».
3. **1:20–2:00 «Сообщить».** Переключить на EN: «Нет туалета» → точка у Чкаловской лестницы → «Отправить». Номер обращения. «Без VK-входа и регистрации».
4. **2:00–2:30 «Панель города».** Открыть панель: «Ваше сообщение уже в счётчике и на тепловой карте; остальное — синтетика (плашка „демо-данные“)». Показать категории и районы — «это то, чего у города сейчас нет по гостям».
5. **2:30–2:50 ИИ-маршрут.** «2 часа, история и закат, без больших подъёмов» → маршрут с закатом последним, «выходите около…», официальные ссылки/«уточнить». Если интернета нет — сказать «работает и офлайн».
6. **2:50–3:00 Побратимы.** «Минск» → приветствие и «у вас / у нас». Слайд «как масштабируем на Минск, Гомель, Витебск, Сухум».

## Известные ограничения

- Афиша, панель и тексты побратимов — демо/черновик; нет интеграции с реальными API города (обращения, афиша).
- Линии маршрута на карте — прямые между остановками, не пешеходная навигация (есть кнопка «Открыть в Яндекс Картах»).
- Закатные точки отобраны по описаниям; направление проверять на месте.
- Нет аккаунтов и серверного хранилища: сообщения живут в `localStorage` устройства.
- Тайлы OSM требуют сети; без неё карта серая (остальное работает из кеша после первого открытия).
