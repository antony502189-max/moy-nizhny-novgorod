# Мой Нижний Новгород

Городской справочник и гостевой путеводитель работают как один статический сайт. Для обычного запуска нужны только файлы сборки. После первой загрузки и установки service worker оба режима открываются без сети, включая фото, карты и базу домов.

| Раздел | Что доступно на устройстве |
| --- | --- |
| Для гостей | Афиша с датами и источниками, расчёт заката, 861 объект городской инфраструктуры, исторические фото и игра, приветствия на русском, английском и китайском |
| Прогулки | Планирование по запросу, интересам, времени и личным оценкам. Пути между 21 остановкой по уличной сети, профиль без отмеченных лестниц, сохранение и ссылка |
| Для жителей | 54 объекта, 6 прогулок, личные маршруты и дневник. Поиск среди 9 805 домов, контакты УК, импорт CSV/JSON, резервная копия |
| Обращения | Черновик с фото и координатами на устройстве, текст для переноса в интернет-приёмную. Панель показывает локальные записи по границам восьми районов. Демо-данные включаются отдельно |

Из гостевого интерфейса в городской ведёт ссылка «Для жителей». Вернуться можно с главной городского режима. Старые ссылки на дома, прогулки и избранное и ранее сохранённые в этом браузере данные продолжают работать на прежнем домене.

## Запуск и публикация

Используйте Node.js 22.18 или новее. Установка зависимостей требует доступа к npm. Сборка и тесты используют локальные данные.

```sh
npm ci
npm test
npm run dev
npm run build
npm run preview
```

`npm run build` готовит каталог `dist/`. Его можно раздавать по HTTPS из корня или подпапки, а локально — с localhost. Для GitHub Pages с публикацией из корня ветки выполните `npm run pages:prepare` и включите обновлённые `index.html`, `resident.html`, `sw.js`, `bundle/` и изменённые статические ресурсы в коммит. Корневой сайт уже содержит подготовленную сборку. Шаблоны для разработки лежат в `guest.html` и `city.html`, исходники — в `src/` и `resident/`.

После сборки браузерная проверка запускается командами `npx playwright-core install chromium` и `npm run test:browser`. Для уже установленного Chromium можно указать путь к исполняемому файлу в `CHROMIUM_PATH`. Проверка открывает сайт в подпапке, отключает сеть и проверяет карты, архивные фотографии, сохранение снимков прогулки и нижнее меню при увеличении текста.

## Актуальность и данные

- Афиша хранится в `src/data/events.json`. У записи есть идентификатор места, время начала со смещением UTC, название на трёх языках и ссылка организатора. Обновляйте список и поле `checked` вместе. После последнего события приложение показывает дату сверки и ссылку на полную программу. [Программа Арсенала](https://arsenal-museum.art/events-all/)
- Дома взяты из снимка ГИС ЖКХ. Происхождение, дата и лицензия сохранены в `housing/manifest.json`. Личная выгрузка живёт отдельно в IndexedDB. [Источник данных](https://tochno.st/datasets/gisgkh)
- Карты, пути и районы обновляются при подготовке выпуска. Удобства обновляются отдельно командой `npm run data:amenities`. [Воспроизведение картографии и лицензия](maps/README.md)
- Метаданные фотографий приведены в `places/credits.json`, `src/data/photoCredits.json` и `src/data/history.ts`. Карточки и исторические сравнения содержат ссылки на авторов и лицензии. Губернская гимназия на архивном фото относится к зданию на ул. Ульянова, 1. Современная фотография показывает это же здание. [Отчёт Мининского университета](https://mininuniver.ru/sveden/files/rix/Otchet_o_rezulytatx_deyatelynosti_za_2025_god.pdf)
- Город получает обращение после того, как пользователь отправит его через приёмную. Личные оценки, избранное и черновики остаются в браузере. Дорожная ситуация, отключения, регистрация на события и покупка билетов доступны по внешним ссылкам. [Интернет-приёмная администрации](https://admgor.nnov.ru/reception/reception-form)

## Аудиогид и режим прогулки

В разделе «Тогда и сейчас» метки на карте и поиск по названию или адресу открывают фотохронологии всех 54 достопримечательностей. У бывшей губернской гимназии есть дополнительная карточка. В каждой серии три исторических кадра и современный вид с датой съёмки. Свайп или нажатие на миниатюру переключает кадр, а «Где это» возвращает на карту к выбранному месту. Под каждым изображением приведён источник, реконструкции отмечены прямо на изображении. Подписи и атрибуции находятся в `src/data/history.ts` и импортируемых им наборах кадров.

Русские аудиозаписи для достопримечательностей и исторических кадров входят в выпуск. Озвучивание на других языках использует голоса устройства. Кнопка «Начать прогулку» сохраняет прогресс. С разрешения пользователя геолокация предлагает рассказ в радиусе 100 м. После последней остановки можно прикрепить фотографии. Авторы гостевых историй указывают имя или псевдоним. Тексты, личные оценки и фото сохраняются в браузере, историями можно обмениваться.

Для редакционного обновления сохраните серверный ключ в окружении процесса и выполните команды из корня репозитория. Первая команда повторно использует выпущенные рассказы с теми же источниками и моделью. Для русских аудиозаписей используются eSpeak NG и ffmpeg.

```sh
node --experimental-strip-types scripts/prepare-stories.mjs
node scripts/render-narration.mjs /path/to/espeak-ng.js /path/to/ffmpeg
```

## Необязательные онлайн-функции

GitHub Pages раздаёт готовые рассказы и использует местный планировщик без ключей. Диктовка доступна в браузерах с Web Speech Recognition. Обработка речи зависит от браузера и его разрешений. Для онлайн-маршрутов и распознавания записи через DeepSeek разверните функции `api/tour.ts` и `api/voice.ts` на сервере с HTTPS.

- На сервере задайте `DEEPSEEK_API_KEY`, `TOUR_API_ENABLED=1` и параметры общего счётчика `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`. Допускается 5 обращений в минуту и 100 в сутки на весь сайт. При недоступности счётчика обработка останавливается до вызова провайдера. [Redis REST](https://upstash.com/docs/redis/features/restapi)
- При сборке клиента задайте адреса функций `VITE_TOUR_API` и `VITE_VOICE_API`. При одном домене это `/api/tour` и `/api/voice`. Для сайта на другом домене укажите абсолютные HTTPS-адреса функций и внесите origin сайта в серверный список `PUBLIC_APP_ORIGINS`.
- Планировщик Андрея поддерживает также Anthropic и совместимые с OpenAI провайдеры через параметры из `.env.example`. Ответ модели проходит проверку остановок, времени, нагрузки и путей. Если ответ не подходит, маршрут строится на устройстве. При голосовом вводе через DeepSeek отправляется выбранная пользователем запись продолжительностью до 30 секунд. [Распознавание речи DeepSeek](https://api-docs.deepseek.com/guides/asr/)
